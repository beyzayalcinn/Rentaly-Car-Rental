RENTALY - ARAÇ KİRALAMA SİSTEMİ

Rentaly, ASP.NET Core MVC kullanılarak geliştirilen bir araç kiralama web projesidir. Proje kapsamında araçların listelenmesi, araç detaylarının görüntülenmesi ve kiralama rezervasyonlarının yönetilmesi amaçlanmaktadır.

PROJE ÖZELLİKLERİ

Araçları listeleme ve araç detaylarını görüntüleme

Araç marka, model ve kategori bilgileri

Kiralama noktası ve tarih seçimi

Rezervasyon işlemleri

Yönetim paneli üzerinden kiralama işlemlerinin yönetimi

KULLANILAN TEKNOLOJİLER

C#

ASP.NET Core MVC

Entity Framework Core

Microsoft SQL Server

HTML, CSS ve JavaScript

Bootstrap

PROJENİN AMACI

Bu proje, web uygulaması geliştirme, veritabanı yönetimi ve katmanlı mimari konularında deneyim kazanmak amacıyla geliştirilmiştir.
